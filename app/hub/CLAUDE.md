# Phone field terminal — details (loaded when working here; core mobile rules are in root CLAUDE.md)

- Phone = atelier field terminal: capture, fix metadata, nudge pipeline. Desktop = heavy PR / CRM / dashboards.
- **Phone work images:** Lightroom Mobile → Export (JPEG) → iOS Share Sheet → PWA `share_target` → `/atelier/share-receive` → `WorkForm` or **work session** (`/atelier/session/new` → Lightroom workflow steps → Share back → triage **Add to work session**). No `lightroom-cc://` from the PWA (iOS often refuses). No native `capture="environment"` on work paths (`WorkForm`, `WorkDrawerImageArea`). Exceptions: business-card capture `/atelier/capture?mode=card` (`CaptureCardClient`) and session / concept native capture.
- Phone navigation (option A, 2026-11-18, `docs/design/2026-11-18/PhoneNav.notes.md`): no side drawer on the phone. ☰ opens one menu sheet, the same on `/hub`, `/hub/fil` and the Atelier phone header (`components/shared/PhoneMenu.tsx` → `PhoneMenuSheet.tsx`): « #numéro ou titre » search, 9 tiles with counts, « Tout le reste », « Actions », account. Home = **Aujourd'hui** (`/hub`, `?day=`); phone Journal = list of days; Écrire = sheet over the day.
- `/hub` mobile entry changes → smoke WorkForm, WorkDrawer, Inventory at small viewport; `npm run test:e2e:field` when a logged-in dev session is available.
- Rings: A Atelier narrow chrome; B Hub day screen + phone menu + input bar + `VoiceNoteSheet`; B.3 PWA share target; C field verb routes / stubs + business-card capture.
- Phone / LAN dev: `DEV_AUTO_LOGIN_*` in `.env.local`, open `/hub` on the LAN URL (`pwsh scripts/dev.ps1` prints it). No Google OAuth on `192.168.*` unless in the Supabase Auth redirect allowlist. Use the real PEM account email in `DEV_AUTO_LOGIN_EMAIL` to see the same `work_session` rows as prod.
