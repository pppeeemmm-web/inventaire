# Rethink — Pem, 2026-11-14

Pem's reflection on the whole experience, written down as said (lightly ordered). **Not a plan and not a GO.** Next step = design first (think it through, one screen at a time), then build. Nothing here is to be tweaked into the current screens.

## What went wrong lately (Pem)

- Debugging takes a long time; pure design and UX "kind of let down recently, not thought through, just tweaked".
- "I'm adding layers and layers … implementing things that don't bring anything really. The way I thought they would be implemented, they would serve something."

## The big pieces Pem named

1. **Slideshow** — "will be a good addition" (design already sketched in [HANDOFF NEXT §6](./HANDOFF_2026-11-14_NEXT.md)).
2. **Mobile terminal, reprioritized** — towards the day-to-day things Pem can do, not the sales and stuff on the welcome page.
3. **Timeline + map extension + previews.**
4. **Work drawer reworked** — "so much information that needs to be visually organized"; a quicker glance at everything, in a more organized way. "That's going to be a big one." (Supersedes the small "empty fields folded" item, NEXT §4.)
5. **Remove the confusion** around research, concepts, voice notes, writings, the AI suggestions and the search — "a bit awkward". Search has been "very strange"; re-indexing the whole thing every time takes a while (embedding used to be one by one). Pem: no need to elaborate on search for now.

## How Pem works: inputs → outputs

**Inputs** (to nourish the practice: concepts, snippets, ideas, texts, images):
- **Images** — photographs, or a document whose text can be extracted (OCR, like the Windows Photos app does).
- **Voice notes** — keep as the main spoken input. Dictation "almost not working" without an AI system on the phone.
- **Writings.**

Pem wants these organized in a better way: the current split (Research / concepts / voice notes / "reminders or whatever you call it") "is just very strange. It all adds up and it doesn't come through nice and useful."

**Outputs** — paintings, drawings, anything produced (sculptures, digital paintings…), entered through the **work sessions**.
- Writings can also be an output — left for now.
- Photographs as an output need a different system altogether (maybe on the same organization) — too big for this system, another time.
