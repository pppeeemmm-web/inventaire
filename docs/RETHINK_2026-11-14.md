## How Pem works: inputs → outputs

**Inputs** (to nourish the practice: concepts, snippets, ideas, texts, images):
- **Images** — photographs, or a document whose text can be extracted (OCR, like the Windows Photos app does).
- **Voice notes** — keep as the main spoken input. Dictation "almost not working" without an AI system on the phone.
- **Writings.**

Pem wants these organized in a better way: the current split (Research / concepts / voice notes / "reminders or whatever you call it") "is just very strange. It all adds up and it doesn't come through nice and useful."

**Outputs** — paintings, drawings, anything produced (sculptures, digital paintings…), entered through the **work sessions**.
- Writings can also be an output — left for now.
- Photographs as an output need a different system altogether (maybe on the same organization) — too big for this system, another time.
